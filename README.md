# Digital Master Sheet

コーヒー提供現場で、6人のドリッパー（抽出担当者）へ注文を割り当て、進行状況を一画面で把握するためのタッチ操作向けUIモックです。iPadの横画面を想定し、管制盤を常に表示したまま操作できます。

## プレビュー

[GitHub Pages](https://210on.github.io/digital-master-sheet/)

`main` ブランチへのpushを契機に、GitHub ActionsからGitHub Pagesへ自動デプロイします。

## 画面

- **A**: NOW線を基準に、6人のレーンと時間軸で進行・待機カードを確認する管制盤
- **B**: 現在・次の抽出と未割当注文を、よりコンパクトに確認する比較案
- 左の縦バーからA/Bを切り替えます。
- 補助情報は右側パネルに表示し、管制盤全体を隠しません。

## 主な挙動

- 初期状態は全ドリッパーが空で、モックのレジ注文 `#001`〜`#120` が順次追加されます。
- 未割当注文と各ドリッパーの待機列は、指名注文を含めて原則オーダー番号順です。
- 指名注文は指定されたドリッパーにのみ割り当てられます。
- 1回の抽出は最大2杯です。3杯以上の注文は2杯以下のカードへ自動分割します。
- 同じメニューの1杯カード同士だけ、利用者の判断で2杯の同時抽出へ統合できます。
- `次へ` を押すまで現在の抽出は継続中です。押した時点を基準に、後続カードすべての開始位置を再計算します。
- 抽出前のカードは、別のドリッパーへの移動または未割当に戻す操作だけができます。
- 通常のホットは無色、氷・牛乳・指名・`★SP` は識別色で表示します。
- `1/1・計1杯` は省略し、分割された注文だけ `1/3・計4杯` のように全体量を表示します。

## タッチ操作

- 未割当カードをタップすると、カードを隠さず上下に1〜6の割当ボタンが開きます。
- 指を離さず割当先へなぞる操作と、レーンへのドラッグ操作に対応しています。
- 枠外をタップすると選択状態を解除します。
- タイムライン上の未開始カードも、同じ操作感で割当先を変更できます。

## 開発

Node.js 22を推奨します。

```bash
npm install
npm run dev
```

開発サーバーは `http://localhost:3000` で起動します。

```bash
npm run lint
npm run build
```

本番ビルドは `dist/` に生成され、公開時のベースパスは `/digital-master-sheet/` です。
